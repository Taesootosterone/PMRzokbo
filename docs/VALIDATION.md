- Mac 앱 설정 화면은 macOS 지원 응답과 컴파일 실패를 브라우저에서 주입해 확인했습니다. 설치 중 닫기·중복 업데이트 방지, 오류 표시·재시도·설치 완료, 390px 화면의 가로 넘침 없음과 실제 화면 캡처를 확인했습니다. 다른 Origin의 중지 요청은 403입니다.

## 장수가 다른 PPTX 가져오기 — 2026-11-13, v1.3.0

사용자의 ‘문항마다 슬라이드 수가 다름’에 맞춰 고정 3장 대신 문항 번호·정답·해설 표시로 경계를 제안합니다. LibreOffice로 화면을 보존하고 Tesseract.js의 한국어·영어 모델로 필요한 페이지를 로컬 OCR 처리합니다. 의학 용어 규칙으로 단원을 추천하며, 사용자가 묶음·정답·분류를 확인한 문항만 등록합니다. PMRtest/NOAH와 기존 사용자 데이터는 변경하지 않았습니다.

- `npm test` **17개 통과**, 프로덕션 빌드와 TypeScript 검사 통과. 실행 프로토콜·DB 스키마는 1을 유지합니다.
- 실제 PPTX 생성기로 표지와 장수가 다른 두 문항을 만들었습니다. 첫 문항은 문제 2–3장·정답/해설 4–5장, 두 번째는 이미지형 문제 6장·정답 7장입니다. 브라우저 업로드 검사는 ZIP에 무작위 시험 데이터를 추가해 **34,719,779바이트(33MiB 초과)**로 만든 합성 파일을 사용했습니다. 큰 파일의 업로드 경로를 검사한 것이며 33MiB의 의료 이미지 부하를 재현한 것은 아닙니다.
- Chromium에서 업로드 → 실제 LibreOffice 변환 → PDF/이미지 생성 → 이미지 속 영어 정답 OCR → 가변 묶음 → 범위·제목 수정 → **검토 초안 저장·새로고침 후 복원** → 선택·확인 후 2문항 등록 → 풀이·해설 확인을 통과했습니다. 발표자노트도 문항의 해설 텍스트로 보존됐습니다.
- 같은 문항을 다시 등록하면 추가 0·기존 2개 유지가 확인됐습니다. 단위 검사에서는 사용자 수정·별표·메모·시도 기록·기존 개념의 NOAH ID/URL도 보존됐습니다. 전체 `.pmrz` 백업을 별도 경로에 복원해 출처·이미지·풀이 기록·연결을 확인했습니다.
- 제출 전 세션 응답에서 정답·해설뿐 아니라 추출한 출처 텍스트도 제외했습니다. 정답 충돌·복수 답·선지 번호만 있는 경우의 미추정, 수동 시작 장 지정, 잘못된 범위와 겹침 거부, 확인하지 않은 등록 거부를 검사했습니다.
- 별도 한글 이미지 OCR 검사에서 신뢰도 79와 `정답: (3)`을 확인했습니다. 동그라미·숫자·영문·괄호 정답 및 라벨/답이 별도 줄인 표기를 단위 검사했습니다. 이 결과는 모든 한글·의학 약어의 인식 정확도를 보장하지 않습니다.
- 390px 세로 화면에서 가로 넘침 없이 검토할 수 있었습니다. 분석 자료를 삭제해도 등록한 이미지와 문항은 남아 실제 풀이가 가능했습니다. 다른 Origin의 등록 요청은 403입니다. 취소는 해당 작업의 취소 표식으로 전달하며 저장된 PID의 다른 프로세스에 종료 신호를 보내지 않습니다.
- 기존 설정 2개·이미지 등록/오답 복습/시험 재개/개념 연결/백업 복원 통합 1개·Mac 제어 프로세스 1개 시나리오도 통과했습니다. Mac 제어는 Linux의 격리된 실제 실행·업데이트 프로세스로 검사했으며 Finder 앱 실행 검사는 아닙니다.
- 웹 업데이트의 자동 다운로드·적용·전체 백업·빌드 실패 보존·실행 실패 복구도 최종 통과했습니다. PPT 시나리오와 합쳐 브라우저 시나리오 **6개를 나누어 실행해 통과**했습니다. 의존성 설치와 빌드가 길어지는 조건에 맞춰 검사 시간 예산과 검사 전용 서버 시작 대기를 늘렸으며 제품의 기본 시작 대기 60초는 변경하지 않았습니다.

**검증 경계:** 첨부한 실제 2023년 시험 PPTX는 채팅 파일 전송 도구의 **32MiB 제한** 때문에 내려받지 못했습니다. 원본을 열어 문항 수·묶음·정답·분류 정확도를 확인하지 못했으며, 위 검사는 직접 만든 데모 자료입니다. 실제 macOS LibreOffice·Safari, 실제 사용자 PPT의 글꼴·레이아웃·초대용량 변환은 미검증입니다. 규칙 기반 단원 추천은 의료 내용의 정답 판정이나 임상 지식 검증이 아닙니다. 원본 PPT와 미등록 초안·변환 캐시는 전체 백업에 포함하지 않으므로 원본을 따로 보관해야 합니다.
